# Workshop

Preview: `index.html?room=workshop&view=room&layout=spacious`.

Plywood, teal cabinets, charcoal steel, amber details and a concrete floor
create an organized maker space. A 900 mm workbench carries the library chop
saw, drill, mallet, toolbox and oscilloscope. Original fixtures include drawer
storage, a pegboard tool wall, bench vise, prototype printer and upright timber
rack. Linear ceiling lights and four practical lights illuminate working areas.

Larger rooms add the library shop machine and industrial toolbox, then an
assembly island with the cutter machine, a rolling clamp rack, an enclosed CNC
station and parts bins. The largest adds a laser and finishing station plus a
display of sample projects. Original equipment is illustrative, with physical
dimensions and editable Studio groups; library tools retain their native size.

Morning, Afternoon, Evening, Night and Open workshop adjust daylight, task
lighting, desk placement, lift, tilt and LEDs. Room and desktop width can be
selected independently. Layout edits and modes are stored separately and
preserved through project export/import. Full-floor Glide respects the room
boundaries; furniture collision avoidance is not simulated. Inspiration props
do not affect pricing and are excluded from AR export.
