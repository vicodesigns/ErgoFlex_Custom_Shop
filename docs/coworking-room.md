COMMON / GROUND uses warm oak, sage, terracotta, speckled concrete, city
windows and suspended task lights. Each size includes a café counter,
community noticeboard, conversation or collaboration table and soft seating.
The hub adds an acoustic focus booth; the two largest layouts add an enclosed
call booth. Planter dividers separate work and social areas.

The rear-left desk is the active ErgoFlex. Secondary desks are snapshots of
the actual configured model, batched by material with grain textures preserved.
They show a digital creator, remote collaborator, illustrator, researcher and
founder as the room grows. Main lift, tilt and Glide leave those desks fixed.
Chairs and props retain their physical sizes when switching desktop widths.

Morning, Afternoon, Evening, Night and Community social update daylight,
practical lighting, desk posture and position. Four practical lights add no
shadow maps. The city canvas redraws on mode changes without a drawing loop.

Room size is independent of desktop width after initial selection. Scene edits
and presentation settings persist per layout and through project save/restore.
Full-floor Glide uses room boundaries; furniture collision is not simulated.
Inspiration furniture does not affect the purchase price or desk AR export.

Verification: `npm run test:coworking`. The screenshot helper supports
`--coworking-layout` and `--coworking-mode`. The website package file list
includes the new module; this local change does not publish it.
